# tp-integrador-icsw
8.a - ¿Qué documentarían en el README?
Documentaríamos el propósito general del sistema, los requisitos previos de instalación, los comandos exactos para levantar los entornos de desarrollo, cómo ejecutar las pruebas automatizadas y la estructura básica del proyecto.

8.b - Modificaciones de externos 
A un externo le pediríamos que detalle: la motivación del cambio, qué problema resuelve, los pasos exactos para reproducir las pruebas locales y si el cambio rompe alguna compatibilidad previa.
Para automatizar esto, GitHub nos ofrece los Pull Request Templates. Al crear un archivo 
.github/pull_request_template.md, GitHub precarga un formulario con estas preguntas automáticamente cada vez que alguien abre un PR.
